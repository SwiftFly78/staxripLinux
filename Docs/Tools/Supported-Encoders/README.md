# [Documentation](../../README.md) / [Tools](../README.md) / Supported Encoders

StaxRipLinux comes with encoder profiles for many video and audio encoders. A profile is an encoder with its settings,
the menus of the [Video](../../Usage/User-Interface/Main.md#video) and [Audio](../../Usage/User-Interface/Main.md#audio)
cards list them, `Edit Profiles...` in these menus adds, renames and removes profiles, and *Save Profile...* in the
options of an encoder saves the current settings as new profile.

- [Video Encoders](Video.md)
- [Audio Encoders](Audio.md)

Which encoder to use for which purpose is described in the guides for [video](../../Guides/Encoder/Video.md) and
[audio](../../Guides/Encoder/Audio.md) encoders.
